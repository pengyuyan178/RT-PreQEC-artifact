# `table/` — paper table and figure data

CSV data behind every table and figure in the RTSS 2026 submission.

The manifest documenting both this directory and `../figure/` is
**[`../figure/README.md`](../figure/README.md)** — it maps each file to the paper element
it feeds, notes the two mode-name mappings that aren't obvious from the paper
(`rt_qec_ai` = RT-PreQEC, `rt_qec` = "Heuristic runtime"), gives a runnable snippet that
redraws figures 3–6 from `figure_data/`, and records what was verified against the
published PDFs and LaTeX.
